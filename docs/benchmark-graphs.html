SSD-backed prompt-state reuse for local agent workloads

Dataset date: 2026-06-03 Model focus: gpt-oss-20b GGUF Workload: Printy / Print-a-Bot agent loop

Abstract

These figures summarize the current Flashcache benchmark evidence. The results do not merely show that prompt caching exists; they show where SSD-backed inference state may become useful for ordinary local-agent machines. Warm sessions are much cheaper than restarted sessions, exact replay is only a control, small-prefix gains depend on backend behavior, and the new persistent/hot-cache runs show that reusable-prefix savings become much clearer once process startup and cold cache-fill noise are separated. Whole-slot files still grow quickly enough that the next layer must measure restore-once session residency, layout, and I/O.

Methods And Reproduction
