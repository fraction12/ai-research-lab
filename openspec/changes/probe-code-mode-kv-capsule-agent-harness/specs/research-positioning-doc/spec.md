## ADDED Requirements

### Requirement: Separate runtime-harness mechanism claims
The documentation SHALL separate claims about KV capsule state reuse, Code mode tool-surface compression, compact visible evidence, and context scheduling when summarizing local-agent runtime-harness experiments.

#### Scenario: Reader reviews a combined harness summary
- **WHEN** a Track 02, Track 03, or Track 04 document summarizes a Code mode plus KV capsule experiment
- **THEN** it identifies which controls support hidden KV contribution, which controls support tool-surface compression, which controls support visible evidence scheduling, and which findings are only runtime-harness integration evidence
- **AND** it marks disallowed claims when fresh-tail, wrong-capsule, full-visible, or live-append controls make a result uninterpretable
