## ADDED Requirements

### Requirement: Document emerging agent tool-use surfaces
The documentation SHALL preserve source-backed research notes for emerging agent tool-use surfaces before the lab treats them as candidate research directions or design inputs.

#### Scenario: Reader evaluates a new agent tool-use mechanism
- **WHEN** a reader opens a lab-level research note about an emerging tool-use mechanism
- **THEN** the note explains what the mechanism is, how it works, and which claims are already established by source documentation
- **AND** it identifies relevance to the lab's local-agent research tracks
- **AND** it lists risks, open questions, and smallest useful experiments
- **AND** it preserves source links for verification
