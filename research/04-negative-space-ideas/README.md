# Negative-Space Research Ideas

This is the lab's research ideas folder.

Use it for frontier scans, marked-off prior art, and candidate gaps that might become future tracks.

## Current Best Gaps

1. Correctness contracts for stateful KV reuse.
2. Role-aware agent context compilation.
3. Intentional recompute as a quality repair tool.
4. Model-specific safe-reuse envelopes for local non-frontier models.
5. Consumer SSD and AI-PC co-design for local agent traces.
6. Local persistent KV privacy, deletion, and cross-project isolation.

## Promotion Rule

An idea can become a track only after it has:

- a named prior-art boundary
- a mainstream assumption it challenges
- a measurable hypothesis
- a smallest falsifying test
- expected artifacts
- a stop rule
